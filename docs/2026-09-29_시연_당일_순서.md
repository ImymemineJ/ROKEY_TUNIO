## 3. 네트워크 맞추기

**두 PC 모두, 새로 여는 터미널마다** 한다.

```bash
export ROS_DOMAIN_ID=10
```

Wi-Fi 에서 서로 안 보이면 Discovery Server 를 쓴다 (고정 IP 는 정정인 PC 만 필요).

```bash
# 정정인 PC — 전용 터미널 하나를 이걸로 계속 띄워 둔다
fastdds discovery -i 0 -l 0.0.0.0 -p 11811

# 정정인 PC — 다른 터미널들
export ROS_DISCOVERY_SERVER=127.0.0.1:11811

# 로봇 제어 PC — 모든 터미널
export ROS_DISCOVERY_SERVER=<정정인 PC IP>:11811
```

Discovery Server 를 쓰는 중에 `ros2 service list` · `ros2 param` 같은 명령이 아무것도 못 찾으면
그 터미널에서 `export ROS_SUPER_CLIENT=TRUE` 를 한 번 더 한다.

## 5. dry_run 점검 — 버튼과 연결만 본다

정정인 PC 새 터미널에서:

```bash
ros2 service list | grep robot
```

- [ ] `/robot/pause` 와 `/robot/resume` 이 보인다
- [ ] `ros2 param get /task_manager adaptive_gain` → `True` (자동 보정 켜짐)

웹에서 차례로 누른다. 로봇은 안 움직인다.

- [ ] **페그 재등록** → "재등록·복귀 완료" 가 뜬다
- [ ] **시작** → 6번 줄부터 단계가 진행된다
  - 발현 단계에서 로봇은 안 튕기므로 **사람이 손으로 그 줄을 한 번 튕기면** 마이크 측정까지 확인된다. 안 튕기면 '소리 부족' 으로 넘어가도 정상
- [ ] **일시정지** → 단계 표시가 "일시정지" 로 바뀌고 진행이 멈춘다
- [ ] **재개** → 이어서 진행된다
- [ ] **취소** → "취소" 로 끝난다

여기서 "미연결" · "goal 거부" · 응답 없음이 나오면 **8절**.
dry_run 에서는 취소 뒤에 로봇 노드를 다시 켤 필요가 없다.

## 6. 실기 — 로봇을 움직인다

로봇 제어 PC 터미널 2 를 Ctrl+C 로 끄고 다시:

```bash
ros2 launch tunio_robot robot.launch.py dry_run:=false
```

- [ ] 웹 **페그 재등록** → 네 줄 등록 후 대기 자세로 복귀
- [ ] **시작** → 첫 줄이 튕겨지고 측정된다
- [ ] 일시정지 시험 — **팔이 허공에서 이동하는 중에만** 누른다 (줄 · 페그 · 거치대에 닿아 있을 때는 누르지 않는다)
  - [ ] 그 자리에서 멈춘다
  - [ ] 재개하면 이어서 움직인다
- [ ] **취소** → 멈추고 "취소" 로 끝난다
- [ ] **취소했으면 로봇 노드를 다시 켠다** (터미널 2 Ctrl+C → `dry_run:=false` 로 다시). 안 켜면 새 동작을 전부 거부한다
  - 켜기 전에 피크를 쥐고 있는지, 기타에 닿아 있는지 눈으로 본다

일시정지가 **한 번이라도 이상하면** 시연에서는 일시정지를 쓰지 않고 취소만 쓴다.

## 8. 막혔을 때

**웹이 "연결 중" 에서 안 넘어간다**
- station 런치 터미널에 에러가 있는지 본다
- 두 PC 의 `ROS_DOMAIN_ID` · `ROS_DISCOVERY_SERVER` 를 다시 확인 (3절)

**"로봇 일시정지 서비스 미연결" · "정지/상태 서비스 미연결"**
- 로봇 제어 PC 에서 두산 브링업(터미널 1)이 떠 있는지
- `ros2 service list | grep dsr_controller2` 로 두산 서비스가 보이는지
- 일시정지 · 재개가 "거절" 만 된 경우 작업은 계속 돈다. 다시 누르거나 취소하면 된다

**"goal 거부 (로봇: …)"**
- 괄호 안이 로봇이 말한 이유다
  - "현장 복구 확인 · robot_controller 재시작 필요" → 로봇 노드를 다시 켠다
  - "'...' 실행 중" → 이전 동작이 아직 안 끝났다. 잠시 기다린다
  - "페그 등록값 없음" → 페그 재등록부터

**일시정지 · 재개가 이상하다 (안 멈춤, 재개 안 됨, 바로 취소로 넘어감)**
- 시연에서는 일시정지를 빼고 **취소만** 쓴다

**취소 뒤 아무것도 안 된다**
- 정상이다. 로봇 노드를 다시 켠다 (6절)

**호박색 "로봇 알림: 피크 … 홈 복귀 완료" + 일시정지** (피크 보충 대기)
- 로봇이 피크를 못 집고 홈에 서 있는 것
- 피크를 거치대에 다시 꽂고 → 웹 **재개**. 같은 줄부터 다시 한다
- 여기서 **취소**하면 로봇 노드를 다시 켜야 재등록이 된다

**페그를 너무 많이 / 적게 돌린다 (자동 보정이 이상하다)**
```bash
ros2 param set /task_manager adaptive_gain false
```
- 다음 조절부터 yaml 값 그대로 돌린다. 재시작 필요 없다. 기록은 계속 남는다

**측정이 계속 '소리 부족'**
- 마이크 장치 번호(`device:=`), 마이크 위치, OS 마이크 향상 기능이 꺼졌는지

**그래도 안 된다 → 9절로 버전을 내린다**
